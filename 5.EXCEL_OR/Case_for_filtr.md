# Кейс: Фильтрация в Excel по двум столбцам с логикой «ИЛИ» через вспомогательный столбец

## Описание задачи
Необходимо отфильтровать таблицу по двум условиям в разных столбцах так, чтобы отображались строки, удовлетворяющие **хотя бы одному** из критериев (логическое **ИЛИ**). 

Стандартный автофильтр Excel при выборе критериев в разных колонках всегда работает по логике «И» (строгое совпадение всех условий). Для обхода этого ограничения применен метод **вспомогательного столбца** с флагами `1` и `0`.

### Исходные условия:
* **Условие 1:** В графе `U` значение должно быть больше `0` (`U > 0`).
* **Условие 2:** В графе `X` (содержит дату) значение должно быть меньше октября (`X < 01.10.2026`).

---

## Пошаговое решение

### Шаг 1. Создание вспомогательного столбца
Создайте новый столбец рядом с таблицей (например, столбец `Y`) и назовите его `Проверка`.

### Шаг 2. Внедрение формулы
Вставьте в первую рабочую ячейку столбца (например, `Y2`) следующую формулу и протяните её вниз до конца таблицы:

```excel
=ЕСЛИ(ИЛИ(U2>0; X2<ДАТА(2026;10;1)); 1; 0)
```

> **Важно:** Поскольку Excel хранит даты как числа, для корректного сравнения используется функция `ДАТА(год; месяц; день)`. Граница `ДАТА(2026;10;1)` означает, что под условие «меньше октября» попадут все даты до 1 октября 2026 года (сентябрь, август и ранее).

### Шаг 3. Применение фильтра
1. Выделите шапку таблицы и включите автофильтр горячими клавишами `Ctrl + Shift + L` (или через вкладку **Данные** ➔ **Фильтр**).
2. В созданном столбце `Проверка` нажмите на стрелочку фильтра.
3. Снимите выделение со всех значений и установите галочку **только на цифре `1`**.
4. Нажмите **ОК**.

---

## Результат
Таблица мгновенно скроет строки, не соответствующие критериям. На экране останутся только те строки, где выполненно хотя бы одно из условий (или оба сразу), а сама формула пересчитается автоматически при изменении исходных данных.

## Преимущества подхода
* **Универсальность:** Работает во всех версиях Microsoft Excel.
* **Наглядность:** Легко проверить, почему конкретная строка попала в выборку (флаг `1`).
* **Производительность:** Фильтрация по одному числовому столбцу происходит быстрее, чем использование сложных массивов или расширенного фильтра на больших объемах данных.
